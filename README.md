## 🚀 Key Features of this Portfolio

- **100% Zero-Build Architecture:** Entire application runs directly from a single, self-contained `index.html` file with zero Node.js dependencies, bundlers, or compile steps.
- **Trilingual Internationalization (DE / EN / FA):**
  - **German (`de` - Default):** Formal European engineering terminology (DIN standards, VDI guidelines).
  - **English (`en`):** International engineering dossier format.
  - **Persian (`fa`):** Authentic Persian typography powered by **Vazirmatn** with bidirectional RTL layout.
- **Dual Calendar Engine:** Single-click toggle between **Gregorian (AD)** and **Solar Hijri (Jalali / شمسی)** calendars.
- **European Standard DIN A4 Print Resume:** Clicking **"PDF Resume"** automatically formats the dossier into a crisp, exactly **2-page European Curriculum Vitae** without web card clutter.
- **Integrated Visual CMS & Editor:** Built-in live editor enabling in-place text modifications, adding/editing career milestones and projects via modal forms, reordering, and exporting to JSON or standalone HTML.
- **Click-to-Action Contact Integration:** Direct `mailto:`, `tel:`, LinkedIn profile, and Google Maps location actions with copy-to-clipboard buttons.

## 📂 Quick Start & Local Execution

No installation, build tools, or server setup is required.

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Sarahosseiniboroujeni/mohsen-karim-khah.git
   ```
2. Double-click `index.html` to open it immediately in any web browser (Chrome, Firefox, Edge, Safari).

## 🌐 Deployment to GitHub Pages

To host this portfolio live on GitHub Pages:

1. Ensure the repository contains `index.html` in the root folder.
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. Your website is live at:
   `https://sarahosseiniboroujeni.github.io/mohsen-karim-khah/`
